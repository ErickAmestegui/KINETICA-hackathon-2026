# KINETICA

**Reality to Living Machines.** A local engineering studio that connects video observations to an interactive, equation-driven slider-crank.

KINETICA is a working research MVP, **not arbitrary monocular 3D reconstruction**. It contains a React/Three.js studio, a FastAPI backend, manual video annotation, a local OpenCV tracking baseline, numerical fitting with held-out frames, exports, and real Meta API adapters that are **disabled until explicitly authorized**.

## Run the Reality Lab demo (about 10 minutes, no API key)

> **Media variant: original material only.** This repository ships no third-party footage. The demo clip is an original synthetic rendering generated by `scripts/make_original_demo_clip.py`, labeled on every frame. Its saved geometry is derived from the known motion plus noise and is **not** Meta SAM output.

Windows PowerShell, Python 3.12 and Node.js 22.12+/24, from the repository root:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-lock.txt
Set-Location frontend; npm.cmd ci; npm.cmd run build; Set-Location ..
.\.venv\Scripts\python.exe scripts/prepare_review_demo.py --port 8001
```

Open http://127.0.0.1:8001, then **My machines → Open project JSON → `demo/SYNTHETIC-original-demo-project.json`** and the **Reality Lab** tab:

1. **Observe** — the original synthetic clip and its synthetic geometry (the Reality Lab badge reads **SYNTHETIC TEST**; the Compare overlay's generic "SAM #" box prefix does not make this geometry SAM output). Pick **SYNTHETIC-SLIDER** and confirm it.
2. **Predict** — freeze after frame **74**, horizon **20**. The model assumes constant motor speed; the hidden truth contains a speed ripple.
3. **Reveal** — model **7.67 px** vs constant **52.05 px** and linear **129.82 px** RMSE on the same twenty saved observations. Freezing at frame **49** is refused: timing is not identifiable from fewer than 1.25 observed cycles.
4. **Break Reality** — change geometry; both 3D machines are driven by the constraint solver, impossible strokes are rejected.
5. **Ask the Machine** — **Interpret locally (mock)**: a deterministic, visibly labeled mock proposes a change you must confirm. It is not Muse inference.

2. **My machines → Open project JSON** → `output/kinetica-project.json`, then **Reality Lab**. Inspect object **#2** and explicitly confirm its slider identity; this human assignment is separate from SAM segmentation.
3. In **Predict the Unseen**, set freeze frame **29**, horizon **20**, then **FREEZE REALITY → REVEAL REALITY**. The known source change at frames 37–38 correctly returns `No evaluado`. This is retrospective inspected-data replay; full-video SAM context means causal segmentation is unverified.

5. In **Ask the Machine**, use **Interpret locally (mock)**, inspect `deterministic_mock`, then **Confirm alternate change**. This supported-intent demonstration is local; the failed Muse trial is not presented as a successful live response.
6. **Export replay evidence** and export the project for review. Re-freeze after a session expires; preserved reveal results can be recovered from private storage.

## Windows 11 quick start

Requirements: Node.js 22.12+ or 24, Python 3.12 or 3.13, Chrome or Edge with WebGL. The project was tested with Node 24.16.0 and Python 3.12.14. No GPU model weights are downloaded; 16 GB RAM is sufficient for this bounded local workflow.

From the project root in PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-lock.txt
Set-Location frontend
npm.cmd ci
npm.cmd run build
Set-Location ..
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Open **http://127.0.0.1:8000**. The backend serves the production frontend and API on the same origin. Ctrl+C stops the foreground server.

An existing configured checkout can also start a hidden local server with:

```powershell
.\scripts\Start-Kinetica.ps1
```

Logs and the launcher PID are written to ignored `output/`. Do not bind to `0.0.0.0`; this MVP is a single-user local service, not a hardened multi-user deployment.

If the `py` launcher is unavailable, create the virtual environment with any Python 3.12 or 3.13 interpreter (`python -m venv .venv`).

## First real study

1. Import a front-facing, tripod-mounted MP4/MOV (up to 100 MB, 60 s, 1080p and 3600 frames). Declare real/synthetic footage provenance.
2. In **Compare**, pause. Set origin O on the fixed shaft and set the +x direction along the slider axis. Choose a crank or slider joint tool and click its center. You can draw a component region with two corners; it remains distinct from a joint.
3. Mark more frames manually or **Track locally** from the current seeds. Track losses are reported; reseed at the next visible frame. Clicking an existing joint/frame replaces its sample with a manual correction.
4. In **Motion lab**, set pixels per model unit from a measured reference. Without a physical scale, keep relative units. Use the phase and speed controls for synchronization.
5. Fit requires both joints, at least 12 training samples over 8 distinct frames and coverage of 0.7 revolution at the initial speed. Calibration and eccentricity are held fixed. Initial speed matters because fitting is local, not a global search.
6. Inspect reserved samples. Automatically tracked frames in the final 25% are reserved by default; all joints in a frame share a split. A previously fitted frame cannot silently become independent validation: the metric is withheld until refitting.
7. Export CSV, report and project JSON. A project references its private `data/<id>/` video; it does not embed the video. Preserve that directory when moving a study. Save uses one browser slot; export JSON for multiple studies.

Space plays/pauses; arrows step frames; R resets the camera. Drag orbits, wheel zooms. Video playback rates 0.25–2× keep the simulation clock tied to video time.

## Meta: safe configuration and verification

Read the [final SAM preflight and one-request procedure](docs/SAM_PREFLIGHT.md) and [META.md](docs/META.md) before enabling inference. Current preparation leaves spending blocked. Never send a key in chat.

1. Copy `.env.example` to `.env` **locally** and insert the key privately as `MODEL_API_KEY=...`, or configure that environment variable in Windows before starting the backend. No `VITE_` prefix. `.env` is ignored.
2. Leave `META_ALLOW_PAID=false`. Restart the backend. **Model connections → Check model catalogue** performs only `GET /v1/models`; it does not test inference or billing by spending credits.
3. If you decide to authorize a paid request, set `META_ALLOW_PAID=true` locally and restart. This alone does not send anything. Choose a model and prepare an estimate; review the media transfer and cost, then explicitly authorize the one-time request.
4. Save the actual response and usage in the study report, including diagnostics and incomplete results. A failure must remain a failure. No payment configuration or automatic inference retries are implemented.

The SAM repair kept `META_ALLOW_PAID=false` and made no Meta API requests. See [current repair evidence](docs/SAM_REPAIR.md).
